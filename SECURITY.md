# Security

If you discover a security vulnerability in this project, please report it as follows.

## Non-critical issues

Create a GitHub issue for the vulnerability and ask the maintainer to reach out to you. Do not
put sensitive information in the issue.

## Critical and time-sensitive issues

Send an email to [it-security@equinor.com](mailto:it-security@equinor.com), or phone the Equinor
helpdesk:

- Norway (+47) 51 999 222
- US/Canada (+1) 713 878 6970
